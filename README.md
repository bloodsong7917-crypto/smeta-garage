# Смета и журнал сервиса

Android-приложение для автомастерской: смета по нормо-часам, журнал заказов, напоминания о ТО, редактируемый прайс.

Работает полностью без интернета и без аккаунтов. Все данные хранятся на телефоне, ставку, коэффициенты и прайс каждый настраивает под себя на вкладке «Прайс». При первом запуске подставляется стандартный прайс (72 работы), его можно править и удалять.

Готовый APK — в разделе **Releases**.

## Резервная копия

Вкладка «Прайс» → «Резервная копия»:
- «Сохранить в файл» — выгружает прайс, настройки и журнал в `.json`;
- «Загрузить из файла» — заменяет текущие данные данными из файла (так же переносятся на другой телефон).

## Состав

- `assets/index.html` — само приложение (одна страница, стандартный прайс встроен в неё)
- `src/` — `MainActivity.java`: WebView, сохранение данных в файл, экспорт и импорт копии
- `res/`, `AndroidManifest.xml` — иконка, тема; разрешение на интернет не запрашивается
- `build.sh` — сборка без Gradle: aapt2 → javac → d8 → apksigner

Страницу `assets/index.html` можно открыть и в обычном браузере: тогда данные хранятся в localStorage.

## Сборка

Нужны JDK 17 и Android SDK (platform 34, build-tools 34.0.0); пути заданы в начале `build.sh`.

```sh
export SMETA_KS_PASS=пароль_ключа
sh build.sh
```

Результат: `out/smeta.apk`. Ключ подписи (`smeta.jks`) в репозиторий не входит. Для обновлений поверх установленной версии нужен тот же ключ.
